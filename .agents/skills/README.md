# Generated skill adapters

These are generated copies of `.claude/skills/` for harnesses that read `.agents/skills/`
(Codex, Gemini CLI, Cursor). The sibling `.agents/output-style.md` is the generated copy of
the `partner` reply shape. Regenerated with `python tools/build-adapters.py`.

Do not edit these files by hand — edit the source under `.claude/skills/` and re-run the
build script.
