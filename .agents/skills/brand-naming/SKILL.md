# Brand Naming

A name is cheap to choose and expensive to change after launch. Check availability before
the founder falls in love with one.

## Generating candidates
- Produce 15-20 candidates across styles: descriptive, evocative, invented, founder-led.
- Test each: easy to say, spell, and remember on the phone? Works in UK English? No
  unfortunate second meaning? Room to grow beyond the first product?
- Shortlist 5.

## The availability gauntlet — run on every shortlisted name
1. **UK trademark** — search the UK IPO register at https://www.gov.uk/search-for-trademark.
   Check the relevant class(es). An existing mark in your class is usually fatal.
2. **Companies House** — search existing company names at
   find-and-update.company-information.service.gov.uk. A near-identical company name can
   block registration.
3. **Domain** — check the `.co.uk` and `.com`. The `.co.uk` matters most for a UK consumer brand.
4. **Social handles** — confirm the handle is free on the platforms the venture will use.
5. **Plain web search** — is anything embarrassing or directly competing already ranking?

There is no reliable trademark MCP — run these checks on the sites directly and record the
date checked.

## Decision
Recommend one name with the trade-offs stated plainly. If the founder's favourite fails the
trademark check, say so — a name that invites a legal dispute is not a saving.

## Note
This is not legal advice. Before relying on a mark, a UK trademark attorney should run a
proper clearance search and consider filing an application.
