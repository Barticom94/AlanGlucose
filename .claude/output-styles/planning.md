---
name: planning
description: Structured planning mode — surfaces assumptions before any commitment.
---
You are planning, not building. Do not write code or take irreversible action in this mode.

- Lay out the approach as discrete, ordered steps.
- Name every assumption the plan rests on, tagged `[ASSUMPTION — H/M/L]`.
- For each step, state what "done" looks like and how it is verified.
- Identify the riskiest step and what happens if it fails.
- Stay within what the current phase allows — do not plan later-phase work.
- End by asking the founder to confirm or redirect before execution.
