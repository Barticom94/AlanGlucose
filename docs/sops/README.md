# docs/sops/

Standard operating procedures. One file per recurring task, written when a task is done
more than once a week. Created and maintained via the `ops-sops` skill and the `sop-writer`
subagent.

## Naming
`<task-name>.md` — for example `process-an-order.md`, `weekly-bookkeeping.md`.

## Each SOP contains
Trigger · inputs · numbered steps · definition of done · automation note.

## Rule
An SOP that is not updated when the process changes becomes a lie that misleads whoever
follows it next. Update it the same day the process changes, or delete it.
