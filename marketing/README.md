# marketing/

Customer-facing marketing assets. Drafted by the `copywriter-brand-voice` subagent, which
reads `@docs/BRAND-VOICE.md` first.

## Subfolders
- `landing-pages/` — landing-page and smoke-test page copy. Phase 1 smoke tests live here.
- `email-flows/` — Klaviyo flow copy: welcome, abandoned cart, post-purchase, win-back.
- `ad-creatives/` — paid-ad headlines, primary text, and creative briefs.

## Rules
- Every claim is true and substantiable — UK ASA rules apply. See the `marketing-paid` and
  `copywriter-brand-voice` skills.
- UK English, £ pricing, UK consumer expectations throughout.
- Give 2-3 variants of every headline and subject line so they can be A/B tested.
