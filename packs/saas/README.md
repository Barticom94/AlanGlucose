# Pack — SaaS / Software

Selling subscription software or an app: the customer receives a login, not a box or a
booking. This pack adds the skills and reference knowledge a SaaS venture needs on top of the
core brain — it does not replace the core skills (financial modelling, UK tax, legal
structure, marketing, customer discovery, and so on all still apply).

## When the brain installs this pack
When the intake (`state/business-brief.md`, section 1.2 — "what you'll actually sell") says
the venture sells software, an app, or a subscription product, rather than a physical product,
an online store/marketplace, or a service. Install it at Phase 1 at the earliest, when a
build-route or pricing comparison first becomes useful research — but do not act on anything
in it (build, price, or bill) before the Phase 1 gate: ≥ 3 real commitments (`AGENTS.md`).

## Skills in this pack
- **`saas-mvp-build`** — building the smallest sellable software: no-code/low-code vs
  AI-assisted code vs hiring a developer, concierge and Wizard-of-Oz MVPs, and when real code
  is justified.
- **`saas-pricing-billing-uk`** — SaaS pricing tiers and trials, annual vs monthly, Stripe vs
  a merchant of record (Paddle, Lemon Squeezy), UK VAT on digital services and the post-Brexit
  EU/OSS position, and failed-payment (dunning) handling.
- **`saas-onboarding-retention`** — defining the activation event, designing onboarding,
  tracking D7/D30 retention, logo churn and NRR, the cancellation flow, and UK
  consumer-subscription law.

## Ops reference
- **`docs/SAAS-OPS.md`** — the long-form SaaS operations reference: hosting and cost basics,
  uptime and support expectations, data protection and UK GDPR for a SaaS product, the metrics
  dashboard, and the operating rhythm. Loaded on demand via `@docs/SAAS-OPS.md` — not
  auto-loaded.

## Packs are additive
A venture can use more than one pack — for example, a founder selling a hardware device
(`packs/physical/`) paired with a companion subscription app uses this pack's
`saas-pricing-billing-uk` and `saas-onboarding-retention` alongside `fulfilment-shipping-uk`
and `ops-inventory` from the physical-goods pack, and every core skill besides. Only install
the skills a venture actually needs — an unused skill adds noise, not safety.
