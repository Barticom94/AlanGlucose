# Decisions Log

> Append-only. Newest entry at the top. One entry per real decision. Never edit an old
> entry — if a decision is reversed, add a new entry that supersedes it.

## How to log a decision
Copy this shape, newest at the top:

> **### [YYYY-MM-DD] Short decision title**
> - **Decision:** what was decided
> - **Context:** what prompted it
> - **Alternatives considered:** what else was on the table
> - **Why:** the reason
> - **Supersedes:** an earlier entry, if any
