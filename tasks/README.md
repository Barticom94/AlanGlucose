# tasks/

Lightweight, durable task tracking for the venture, in markdown. The brain uses the
in-session to-do list for live work; this folder holds the phase-level task list that
survives across sessions.

## How to use it
- One file per phase, e.g. `phase-0-validation.md`, or a single rolling `backlog.md`.
- If the founder uses Linear or Notion, mirror it here so the brain can read it.

## Task format
Markdown checkboxes: `- [ ] Task — owner — due date` for open items, `- [x] ...` for done.

## The current Phase 0 task
Interview 10 strangers — not friends, not family — who have the problem.
Gate to Phase 1: at least 3 real commitments (a deposit, a letter of intent, or a waitlist
sign-up with card details).

`state/active_context.md` remains the source of "what next"; this folder holds the fuller list.
